# REFRACTION — v3

Cinematic portfolio by Mohamed Mahmoud.

Live site: https://mohamed3042.github.io/flagship-portfolio-v3/

This repository contains the published static website and delivery media. Native vertical scrolling is the default; journey playback is opt-in. Arabic and English routes are available. Planned camera scenes are labelled in the chapter menu until reviewed videos are supplied.

The site is published from the main branch root with GitHub Pages. Existing v1 and v2 repositories are independent and unchanged by this publication.
